- Admin 전용 `/app/admin/*` shell은 `workspaceRoles.includes("yagi_admin")`로 layout-level gate가 있다. 개별 주요 admin page도 `is_yagi_admin` 또는 `user_roles` 방어가 있다.

- `/app/deals`, `/app/deals/[dealId]`는 BRAND/ARTIST-only route gate가 있다.
- `/app/twins`는 ARTIST-only route gate가 있다.
- 주요 불일치는 app shell / dashboard / projects / campaigns / my-submissions / billing에 집중된다.

## Campaign Lifecycle 집중 점검 결과

- 참여 전: creator가 `/app/campaigns`에서 open campaign을 발견하지 못한다. 현재 `/app/campaigns`는 sponsor-owned campaign list이며 creator empty state는 발주 CTA로 연결된다. Public `/campaigns` list와 `/campaigns/[slug]` detail route도 없다.
- 제출: public submit action은 `campaign.status === "published"`와 `submission_close_at`을 검사한다. 마감 후 제출은 막는다.
- 중복 제출: same creator/email/campaign duplicate guard가 없다. service-role insert가 매번 새 row를 만든다.
- 제출 이후 상태: creator는 `/app/my-submissions`와 detail에서 submitted/declined/revision_requested/approved/distributed label과 latest decision comment를 볼 수 있다.
- Brand/Admin 혼선: sponsor/admin도 RLS로 submissions를 볼 수 있는데 `/app/my-submissions`가 actor gate 없이 creator copy로 렌더된다.
- 분배/수익: creator는 distribution URL과 metric 입력은 가능하지만 compensation/revenue display가 없다.

## 2단계 수정 권장 묶음

1. **App shell role router/nav BLOCKER 묶음**: `/app` landing, TopNav visibility, dashboard fallback을 actor별로 분기. creator 기본은 `/app/my-submissions` 또는 open campaigns, admin 기본은 `/app/admin`, brand 기본은 `/app/explore`/`/app/projects`.
2. **Creator campaign discovery BLOCKER 묶음**: `/app/campaigns`를 role-aware로 split하거나 creator 전용 open campaign list를 만들고, `/campaigns`/`/campaigns/[slug]` broken public route를 정리.
3. **Campaign submission actor gate BLOCKER 묶음**: `/app/my-submissions*`를 creator applicant view로 제한하거나 brand sponsor view를 별도 route로 분리. DistributionPanel은 applicant-only UI gate 추가.
4. **Project creation BLOCKER 묶음**: `/app/projects*`와 project creation actions에 BRAND-only guard를 명시. artist/admin/creator는 route redirect 또는 role-specific empty state.
5. **Billing admin BLOCKER 묶음**: `/app/billing` operations gate를 `user_roles/is_yagi_admin` 기준으로 바꾸고, active workspace kind에 의존하지 않게 수정.
6. **FU batch**: admin invoice labels, Americano/Assets actor copy, creator compensation display, `/app/notifications` route target 정리.
